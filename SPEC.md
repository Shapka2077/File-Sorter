# Спецификация: File Sorter — V1 (черновик)

Статус: черновик одобрен; уточнения заказчика внесены.

## Цель

Настольное приложение для ручной сортировки видео из выбранной пользователем
папки в папку назначения. Видео группируются по датам в отдельных папках.

Пользователь выбирает исходную папку и папку назначения, переключает режим
копирования или перемещения и вручную запускает сортировку. Если в месте
назначения уже есть файл с таким именем, приложение спрашивает пользователя,
как поступить.

## Правила сортировки

- Дата берётся из начала имени файла в формате `ГГГГ-ММ-ДД`; время после даты
  необязательно и не влияет на сортировку. Например,
  `2026-11-19 16-50-20.mp4` помещается в `19.11.26` с сохранением имени.
- Имя папки имеет формат `ДД.ММ.ГГ` с ведущими нулями.
- Если дата отсутствует или некорректна, видео пропускается и указывается в
  отчёте; исходный файл остаётся на месте.
- Переключатель определяет, искать ли видео во вложенных папках; по умолчанию
  поиск выполняется только в исходной папке. При поиске во вложенных папках
  папка назначения не может располагаться внутри исходной.
- Начальные расширения: MP4, MOV, AVI, MKV, WMV, M4V, WEBM. Пользователь
  может добавить свои расширения, которые сохраняются между запусками.
- При конфликте имён предлагаются пропуск, замена, переименование нового файла
  с добавлением ` (1)`, ` (2)` и так далее или остановка сортировки. Ответ
  можно применить ко всем последующим конфликтам. При остановке уже
  обработанные файлы остаются на своих местах.
- При ошибке отдельного файла операция продолжается, ошибка отображается в
  отчёте; исходник не удаляется при неудачном переносе.

## Технологический стек

Python 3 и Tkinter согласованы. Целевые платформы — Windows 10 и 11;
результат распространяется как EXE, не требующий установки Python.
Разработка начата с Python 3.13; для сборки согласован PyInstaller 6.22.3.

## Команды

- Запуск каркаса: `python app.py`
- Тесты: `python -m unittest discover -s tests -v`
- Проверка синтаксиса: `python -m compileall -q app.py validation.py tests`
- Сборка: `.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name FileSorter app.py`

## Структура проекта

- `app.py` — интерфейс приложения.
- `validation.py` — проверка выбранных папок.
- `tests/` — автоматические тесты.
- `SPEC.md`, `tasks/` — требования и план.

## Стиль кода

Код следует соглашениям Python: имена функций и переменных в `snake_case`,
понятная обработка ошибок. Форматтер пока не выбран.

## Стратегия тестирования

- Модульные тесты: извлечение даты из имени, формирование имени папки и
  обработка конфликтов имён.
- Интеграционные тесты: копирование и перемещение файлов в тестовом каталоге,
  без доступа к пользовательским данным.
- Ручная проверка: выбор папок, переключение режима, запуск сортировки и
  взаимодействие с запросом при совпадении имён.
- Использовать стандартный `unittest`; численный порог покрытия пока не задан.

## Границы

- Всегда:
  - сортировку запускает пользователь вручную;
  - пользователь выбирает исходную папку и папку назначения;
  - режим работы выбирается переключателем: копирование или перемещение;
  - при конфликте имён приложение спрашивает пользователя;
  - не перезаписывать существующий файл без явного решения пользователя.
- Сначала согласовать: существенные изменения правил и способа сборки EXE.
- Никогда:
  - не загружать файлы в облако без отдельного согласования и явного действия
    пользователя;
  - не удалять и не перезаписывать файлы молча.

## Критерии успеха

- Пользователь может выбрать исходную папку и папку назначения.
- Пользователь может выбрать копирование или перемещение и вручную запустить
  сортировку.
- Обработанные видео оказываются в папках по согласованному правилу даты.
- При совпадении имени пользователь получает запрос, прежде чем приложение
  выполнит действие с конфликтующим файлом.
- Результаты и ошибки сортировки понятны пользователю.

## Отложено

- Автоматическая выкладка видео в Яндекс Облако — отдельная будущая функция;
  в V1 файлы не загружаются в облако.
- Автоматическое наблюдение за исходной папкой — не входит в V1; запуск
  сортировки выполняется вручную.
