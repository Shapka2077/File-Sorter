# Задачи: File Sorter V1

Исходная спецификация: `SPEC.md`. Правила сортировки и PyInstaller согласованы.

## 1. Согласовать решения, необходимые для реализации

**Результат:** стек, целевые версии Windows и правила сортировки согласованы;
остаётся выбрать инструмент сборки EXE.

**Приёмка:**
- [ ] Решения заказчика записаны в `SPEC.md`; нерешённые вопросы не подменены предположениями.
- [ ] Указаны реальные команды запуска, тестирования и сборки.

**Проверка:** перечитать спецификацию с пользователем и получить согласование.

**Зависимости:** нет. **Файлы:** `SPEC.md`. **Объём:** малый.

## 2. Создать запускаемый каркас приложения

Статус: приложение и тесты созданы, EXE собран; ручная проверка остаётся.

**Приёмка:**
- [ ] Приложение запускается на согласованной Windows.
- [ ] Настроены запуск автоматических тестов и сборка.

**Проверка:** выполнить согласованные команды запуска, тестов и сборки.

**Зависимости:** задача 1, как минимум выбор стека. **Файлы:** определяются
стеком, до 5. **Объём:** средний.

Статус: интерфейс и проверка путей реализованы; ручная проверка пользователем
остаётся открытой.

**Приёмка:**
- [x] В интерфейсе выбираются исходная папка, назначение и копирование/перемещение.
- [x] Недопустимые пути сопровождаются понятной ошибкой; операции пока отключены.

**Проверка:** автоматические тесты проверки путей и ручная проверка интерфейса.

**Зависимости:** задача 2. **Файлы:** интерфейс, проверка настроек, тесты; до 5.
**Объём:** средний.

## 4. Определить назначение видео

**Приёмка:**
- [ ] Видео отбираются, а дата и папка определяются по согласованным правилам.
- [ ] Файлы без распознанной даты обрабатываются согласно решению заказчика.
- [ ] Переключатель управляет поиском во вложенных папках; дополнительные
  расширения можно добавить и сохранить между запусками.

**Проверка:** тесты на даты, некорректные имена, расширения и границы обхода.

**Зависимости:** задачи 1 и 3. **Файлы:** логика отбора и дат, тесты; до 5.
**Объём:** средний.

## 5. Выполнить безопасное копирование

**Приёмка:**
- [ ] Ручной запуск копирует видео в рассчитанную папку без изменения оригинала.
- [ ] Существующие файлы не перезаписываются молча; ошибки отражаются в результате.

**Проверка:** интеграционные тесты во временных папках, включая конфликт и
ошибку операции.

**Зависимости:** задача 4. **Файлы:** логика операций, подключение к интерфейсу,
тесты; до 5. **Объём:** средний.

**Проверка:** интеграционные тесты успешного переноса и ошибок во временных
папках; проверить согласованное поведение для разных дисков.

**Зависимости:** задача 5. **Файлы:** логика операций, тесты; до 5.
